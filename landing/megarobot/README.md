# דף נחיתה — מגה רובוט × CrazyCRM

דף נחיתה פשוט (קובץ HTML יחיד, ללא תלויות) שאוסף לידים ושולח אותם אוטומטית ל-CrazyCRM.

## מה צריך להגדיר (2 דקות)

פותחים את `index.html` ועורכים את בלוק ההגדרות בראש הקובץ:

```js
window.MEGAROBOT_CONFIG = {
  CRAZYCRM_WEBHOOK_URL: "",   // ← כתובת ה-Webhook מ-CrazyCRM
  LOGO_URL: "",               // ← כתובת הלוגו של מגה רובוט
  WHATSAPP_PHONE: "",         // ← אופציונלי: טלפון בפורמט בינלאומי, למשל 972500000000
  SOURCE_NAME: "דף נחיתה — מגה רובוט"
};
```

### 1. כתובת ה-Webhook של CrazyCRM
איך משיגים את ה-URL (לפי ממשק CrazyCRM):
1. נכנסים ל-CrazyCRM → **אוטומציות / אינטגרציות**.
2. יוצרים **Webhook נכנס** (Incoming Webhook) ליצירת ליד.
3. מעתיקים את כתובת ה-URL שנוצרה ומדביקים ב-`CRAZYCRM_WEBHOOK_URL`.

> אם בחשבון שלכם לא קיים Webhook נכנס מובנה, אפשר לחבר דרך **Make**:
> הדף שולח ל-Webhook של Make, ו-Make יוצר את הליד ב-CrazyCRM (פירוט בהמשך).

### 2. הלוגו
מדביקים ב-`LOGO_URL` את הקישור הישיר לקובץ הלוגו מתוך `https://www.megarobot.co.il`.
אם השדה ריק או הלוגו לא נטען — יוצג שם המותג "מגה רובוט" כטקסט (fallback אוטומטי).

## אילו נתונים נשלחים ל-CRM
בשליחת הטופס נשלח `POST` עם גוף JSON:

```json
{
  "fullName": "שם מלא",
  "phone": "050-0000000",
  "email": "name@example.com",
  "company": "שם החברה",
  "message": "פנייה חופשית",
  "source": "דף נחיתה — מגה רובוט",
  "page_url": "https://...",
  "submitted_at": "2026-06-17T10:00:00.000Z"
}
```

מתאימים את שמות השדות למיפוי שמצפה לו CrazyCRM (או ממפים אותם בתוך Make).

## מצב הדגמה
כל עוד `CRAZYCRM_WEBHOOK_URL` ריק — הטופס עובד ב"מצב הדגמה": מציג הודעת הצלחה ומדפיס את הליד ל-Console, בלי לשלוח לשום מקום. נוח לבדיקה ועיצוב.

## חיבור דרך Make (אופציונלי, אם אין Webhook ישיר)
1. ב-Make יוצרים תרחיש חדש עם מודול **Webhooks → Custom webhook**, מעתיקים את ה-URL ל-`CRAZYCRM_WEBHOOK_URL`.
2. מוסיפים מודול **HTTP → Make a request** שפונה ל-API של CrazyCRM ליצירת ליד, וממפים אליו את שדות ה-JSON.
3. מפעילים את התרחיש (Active).

## הרצה / פריסה
זהו קובץ סטטי — אפשר להעלות לכל אחסון: Netlify, Vercel, GitHub Pages, או תיקיית `public` בשרת.
לבדיקה מקומית:

```bash
cd landing/megarobot
python3 -m http.server 8000
# פותחים http://localhost:8000
```

## מה עדיין חסר ממני (הלקוח/אתה צריך לספק)
- **כתובת ה-Webhook של CrazyCRM** — אין לי גישה לחשבון CrazyCRM שלכם.
- **כתובת הלוגו** — סביבת הבנייה שלי חסומה לגישה ל-`megarobot.co.il`, אז לא יכולתי למשוך אותו אוטומטית.
- אם תרצו, אפשר לעדכן את טקסטי השיווק/צבעי המותג לפי הצרכים המדויקים של מגה רובוט.
