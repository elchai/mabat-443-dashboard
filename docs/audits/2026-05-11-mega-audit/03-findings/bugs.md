# Bug Findings — mabat-443-dashboard — 2026-05-11

Scope: same file as security audit (`index.html` ~9715 lines). Findings here are correctness/UX/data-loss issues, distinct from the security findings even where the root cause overlaps.

## P1 — Significant (incorrect output, broken UX, resource leaks)

| # | file:line | Issue | Fix | Effort |
|---|---|---|---|---|
| 6 | index.html:6982-7090 | `arrestSnapToRoads()` doesn't disable its trigger button at start. | 7 | index.html:6589, 6596 | Distance calculations use straight-line haversine even after the user has snapped to roads (which then writes `route.distance` into `routeMeta` at 7076). | 9 | index.html:8723-8736 | `loadPublisherProfiles` does `JSON.parse(JSON.stringify(DEFAULT_PROFILES))` (deep clone) and then merges Firebase data over it. | 11 | index.html:9543-9545 | `Auth.signOut()` doesn't update UI synchronously — it just awaits Firebase. | 12 | index.html:8862-8867 | `handlePhotoUpload`: `file.size > 500000` returns to caller, but the `<input type="file">` value remains set to the rejected file. | 14 | index.html:8504-8513 | `fetchAndRenderHistory` writes `historyBody.innerHTML = ... שגיאה ...` on catch but never resets a loading spinner or retry button. User sees the error and has no way to retry without full page reload. | Add a "Retry" button inside the error state. | S |

## Positive findings (what's done well)

- Geometry validation in the save guard (line 7277) blocks "empty" saves with a context-appropriate hint per activity type.
- Per-activity-type labels (`activityLabels()` at 7198-7206) — clean separation of arrest / checkpoint / observation / ambush in UI strings.
- 20-plan cap in sessionStorage (line 7324) + 50-plan cap in UserPlans (line 9671) — bounded growth.
- AbortSignal.timeout on all `fetch()` to OSRM / Overpass / Mapillary — defends against hung tabs.
- Two-pass route trim past target (lines 7031-7045) — robust handling of OSRM overshoot.
- Wide explicit handling of `auth/popup-closed-by-user` and `auth/popup-blocked` distinctly (line 9535-9539).
- `lookupCoords` falls back through multiple location dictionaries — graceful when source data is partial.
- Stepper UI (`arrestUpdateStepperUI`) visually validates the wizard state machine; the recent commits (`8c7141b`, `0c38047`, `2222d8b`) show the team is actively tightening this.
- Map reparenting between dashboard and operations views (line 5594-5617) is a clever optimization (avoid re-initializing Leaflet).
- All renders go through `renderAll()` after data mutation — no manual partial-render bugs.
- Custom modals (`tacticalConfirm`, `tacticalAlert`) replace browser-native `confirm`/`alert` consistently.
